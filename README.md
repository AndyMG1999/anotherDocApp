
# 📑 AnotherDocApp

anotherDocApp is a personal project application to test the .NET SignalR package used for real-time internet connections (Web Sockets, Polling, etc.).


![alt text](https://i.imgur.com/iIwimEN.png "Dashboard")
## Another Doc Application You Didn't Ask For!
Home to all the features you know and love: bold, highligh, quote and paste images to your hearts content!

![alt text](https://i.imgur.com/NgdRe7t.gif")
## ⚡️Real-time Updates (Even with friends)!
Using the power of .Net SignalR, you can seamlessly save your document and have updates automatically and instantly shown between users. Now you can work on all sorts of papers together!
